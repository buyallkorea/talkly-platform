# TALKLY AI API 운영 관찰

2026-10-25 구현. 관리자 역할로 `/admin/talkly-ai`에서 저장된 최근 1,000건을 요약하고 최근 50건을 펼쳐볼 수 있습니다. 일반 회원에게 노출하지 않습니다.

## 확인 가능한 범위

- 음성 연결 준비 및 학습 요약 생성의 서버 처리 성공/실패, 요청한 모델, 확인된 HTTP 상태, 응답 헤더까지의 시간. 실제 회화 전체 길이나 발화 지연 측정이 아닙니다.
- 요약 Responses API 서버 응답의 usage.input_tokens/output_tokens/input_tokens_details.cached_tokens. 캐시 입력은 전체 입력의 부분집합입니다. 값이 없거나 유효하지 않으면 null/미수집이며 0으로 확정하지 않습니다. 실패한 처리에서도 사용량이 서버 응답으로 확인되면 남길 수 있습니다.
- 실패 구분: 접근 권한(401/403), 요청 한도(429), 제공업체(5xx), 요청 거부(그 밖의 4xx), 타임아웃, 그 밖의 실패. 이것만으로 세부 원인이나 재시도 안전성을 확정하지 않습니다. HTTP 200이어도 연결 등록/요약 검증·저장 단계가 실패하면 처리 실패일 수 있습니다.

## 정확한 비용으로 해석하지 않는 항목

음성 연결 응답은 실제 대화 전체의 음성/텍스트 토큰 사용량을 주지 않으므로 음성 토큰은 저장하지 않습니다. 클라이언트가 보내는 수치를 청구 근거로 신뢰하지 않습니다. 자막 전사 토큰/청구액, 계정 전체 사용량, 환율·세금·실제 청구액, 제공업체 청구 대사와 자동 예산 차단은 미구현입니다. 이미 정산한 연결시간과 이 토큰 표는 서로 다른 지표입니다. 통화 및 요약 처리의 응답 결과 기록도 전체 요청 로그나 청구서가 아닙니다. 고정된 추정 가격을 실제 비용으로 표시하지 않습니다.

## 저장과 장애 격리

`20261025115633_talkly_ai_api_events`를 운영 DB에 적용했습니다. 서비스 역할 전용 RLS 테이블이며 session/kind 고유 키로 중복 기록을 막습니다. 요청 후 Next after에서 최대 1.5초의 DB 요청 제한을 사용합니다. 저장 실패/스케줄 실패는 일반 오류 표식만 로그에 남기고 회화 응답이나 정산 결과를 변경하지 않습니다. 프로세스 종료/배포/연결 장애/요청 제한으로 기록이 누락될 수 있고 watchdog 작업과 함께 실행될 때 표시가 지연될 수 있습니다. 영속 큐나 완전한 과금 원장은 아닙니다.

대화/음성/SDP/원본 제공업체 오류/연락처/API 키/요약 본문은 기록하지 않습니다. API 추가 호출 없이 기존 서버 응답에서 허용된 숫자만 뽑습니다. 모델 상수는 요청 코드와 기록 코드가 공유합니다. 기술 기록 보관 기간은 정식 운영 정책에 포함할 별도 항목이며 학습 요약 3개월 정책을 임의로 적용하지 않았습니다.

메타데이터 화이트리스트/토큰 검증/음성 토큰 미수집/오류 구분/지연 저장/중복 및 저장 실패 격리, DB 제약 및 클라이언트 접근 차단을 코드·독립 PostgreSQL로 확인했습니다. 음성 연결/요약 실제 라우트의 기존 테스트도 함께 실행했습니다. 실제 고객 통화, 새 OpenAI 요청이나 실청구 검증은 수행하지 않았습니다.
