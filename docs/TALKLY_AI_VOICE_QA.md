# TALKLY AI 실제 음성 검증표

상태: **실제 마이크 검증 미실행**. 아래 항목은 코드/가상 이벤트 테스트 통과와 별도로 확인해야 합니다. 개발 preview와 유료 결제 OFF 상태에서 진행합니다. 운영 수업·결제 데이터에 테스트 주문을 만들지 않습니다.

## 순서

1. PC Chrome에서 마이크/스피커를 확인하고 AI 가입·3분 체험을 실행합니다. 일반 회원은 총 3분, 관리자 별도 테스트 이용권은 하루 10분이므로 구분합니다.
2. 아래 회화 사례를 실행하고 화면에 표시된 문장, AI가 말한 내용, 기다린 시간, 오류·중단 시점을 기록합니다. 원음 업로드·녹음 저장을 요구하지 않습니다.
3. 모바일 Safari 또는 Chrome에서도 권한·재생·일시정지를 확인합니다.
4. 관리자 테스트 이용권으로 10분 연결과 약 4분 단위 갱신을 확인합니다. 현재 갱신 시 짧은 끊김이 가능하며 자연스러운 전환 여부는 별도로 평가합니다.

| 항목 | 실행 예시 | 확인 기준 | 실제 상태 |
| --- | --- | --- | --- |
| PC 장치 없음 | 마이크를 연결하지 않고 시작 | 입력장치 안내, 연결 정리, 재시도 가능 | 미실행 |
| 권한 거부 | 사이트 마이크 권한 거부 | 허용 방법 안내, 늦게 열린 마이크 정리 | 미실행 |
| 모바일 재생 | 휴대폰 브라우저에서 시작 | 음성 재생 또는 명확한 재생 허용 안내 | 미실행 |
| 느린 대답 | 질문 후 생각하고 천천히 답변 | 반복 질문·주제 전환 여부 관찰. VAD low가 무제한 대기를 보장하지 않음 | 미실행 |

| 답변 도중 해제 | 생각 중 상태에서 말하다 해제 | 현재 발화가 끝나고 입력 확정 후 응답 1회 | 미실행 |

| 한국어 보조 | I don't understand. / 한국어로 조금만 도와줘. | 짧게 한국어 도움 후 영어로 복귀 | 미실행 |
| 언어 혼선 | 영어·한국어를 번갈아 말하기 | 뜻 없는 일본어·중국어 출력/전사가 생기는지 확인 | 미실행 |
| 주제 기억 | 취미 대화 후 종료·다시 시작 | 최근 맥락을 무리 없이 이어가고 새 주제도 허용 | 미실행 |
| 연결 갱신 | 4분 이상 계속 사용 | 추가 인사 없이 이어가기, 생각 중·확정된 미응답 입력 유지 여부 | 미실행 |
| 일시정지 | 중단 후 30초 기다렸다 재개 | 중단 중 마이크/연결 종료 및 추가 차감 없음 | 미실행 |
| 무료 소진 | 일반 회원 3분 사용 | 서버 종료·잔여 0, 다음 날에도 재지급 없음 | 미실행 |
| 유료 한도 | 관리자 테스트 이용권으로 10분 | 화면 타이머뿐 아니라 provider 종료·DB 정산까지 확인 | 미실행 |

## 코드 검증으로 확인한 범위

`node tests/talkly-ai/turn-coordinator.mjs`: 실제 클라이언트 이벤트 처리 함수를 실행하여 음성 입력 확정 전 대기, 생각 중/발화 중 대기, 기존 응답 완료 후 대기 입력 처리, 중복 입력 이벤트 차단, 무입력 시 새 질문 없음, provider 오류 시 중단을 확인합니다.

의미 기반 발화 감지는 계속 사용하되 자동 응답 생성은 끄고 클라이언트가 확정된 입력에 대해 응답을 요청합니다. 응답 요청 시점에 즉시 pending 처리하여 서버의 response.created 확인이 늦어도 중복 요청을 막습니다. 조용한 시간만으로 응답을 요청하지 않습니다. 기존 lease 길이·예약·환급·요금제·DB는 변경하지 않습니다.

실제 기기·억양·오디오 지연·provider 모델 접근·10분 watchdog은 이 검증으로 입증되지 않습니다. 브라우저와 API 연결 상태에 따른 이벤트 순서 및 반복 갱신을 실사용으로 확인해야 합니다.
